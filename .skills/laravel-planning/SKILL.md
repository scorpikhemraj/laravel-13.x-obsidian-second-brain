# Skill: Laravel Planning

## Description

Skill for product planning, feature specification, user stories, and backlog management for Laravel projects.

## When to Use This Skill

- User wants to plan a new feature
- User wants to create user stories
- User needs backlog management
- User wants feature prioritization
- User needs sprint planning

## Workflow

### 1. Requirement Gathering

1. Understand the user's goal
2. Identify stakeholders
3. Define success criteria

### 2. Feature Breakdown

1. List all features needed
2. Group related features
3. Identify dependencies
4. Prioritize features

### 3. User Stories Creation

1. Write user stories (As a [user], I want [goal], so that [benefit])
2. Add acceptance criteria
3. Define edge cases
4. Add technical notes

### 4. Backlog Management

1. Create product backlog
2. Prioritize items (MoSCoW: Must, Should, Could, Won't)
3. Estimate effort
4. Create sprints

### 5. Documentation

1. Create SPEC.md document
2. Document decisions
3. Share with team

## Example User Story Template

```markdown
## User Story: [Title]

**As a** [user type]
**I want** [goal]
**So that** [benefit]

### Acceptance Criteria
- [ ] Criterion 1
- [ ] Criterion 2

### Edge Cases
- [ ] Edge case 1

### Technical Notes
- Related models: [Model names]
- API endpoints: [List]
- Frontend pages: [List]
```
